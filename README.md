# Game icons: Zuujis free game assets

128 inventory and interface icons, a sprite atlas and editable vector sources. Public-domain **CC0**: use them in commercial or personal games. Credit is optional.

Every file is here on its own: open one on GitHub and use **Download raw file** to save just that file. Or download the whole pack:

**[Download zuujis-game-icons.zip](https://github.com/zuujiscom/free-game-assets/releases/download/v1.0.0/zuujis-game-icons.zip)** · [Preview gallery](https://github.com/zuujiscom/free-game-assets/blob/main/previews/icons/README.md) · [All Zuujis packs](https://github.com/zuujiscom/free-game-assets)

[CC0 terms](LICENSE) · [Credits](CREDITS.md) · [Report how you used them](https://github.com/zuujiscom/free-game-assets/issues/new?template=asset-use.yml)
